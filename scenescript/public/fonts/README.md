# Bundled fonts

Allura, Great Vibes, Parisienne and Sacramento are self-hosted.
Source: https://github.com/google/fonts/tree/main/ofl (allura, greatvibes, parisienne, sacramento).
Each family includes its original SIL Open Font License. No third-party font requests are made at runtime.

Seasonal display families (also self-hosted, with no third-party runtime requests):

- Creepster Regular: https://github.com/google/fonts/tree/main/ofl/creepster
  — original SIL Open Font License in `Creepster-OFL.txt`.
- Mountains of Christmas Regular/Bold: https://github.com/google/fonts/tree/main/apache/mountainsofchristmas
  — original Apache 2.0 license in `MountainsOfChristmas-LICENSE.txt`.

Font binaries are unmodified. The bundled families are exposed in the editor font picker,
validated in project JSON and loaded by the shared preview/export font pipeline.
