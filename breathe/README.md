# Jacktools Breathe
Static Astro tool for https://breathe.jacktools.net.

Use Node >=24.17.0. Run npm ci, npm run dev, npm test, npm run build.
Deploy the complete dist/ contents to the domain root, as with Timer/Clock:
1blu Ubuntu/Plesk, HTTPS, static files, no application backend.
Serve sitemap.xml as application/xml and retain robots.txt. No deployment is performed by the build.

Four languages (DE/EN/ES/FR), shared theme/palette/style settings and bilingual legal pages.
Box breathing, balanced 5–5, gentle 4–6 and custom timings. Holds may be zero.
Sessions are paused when the tab is hidden; reloading does not restore a running session.
Independent locally generated breathing sounds and phase chimes, focus view, screen wake lock, reduced-motion support.
Preferences are saved only with explicit local-storage consent.

Safety: first-start guidance is held in memory, or saved with settings only after storage consent.
A persistent safety reminder and full guidance are reachable in focus view.
End session immediately stops animation/countdown/audio; pause preserves position.
Active holds can be skipped; zero-duration holds remain supported.
Opening detailed guidance pauses the session; returning never resumes automatically.
Safety copy is translated into all four languages and makes no therapeutic promises.
Emergency guidance names 112 specifically for Germany/the EU, not based on UI language.
