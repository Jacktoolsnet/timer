# Company logo vector

jacktools-icon.svg is a vector tracing of jacktools-icon.png (96 × 96),
including all three gears, question mark, exclamation mark, bulb, arrow and smiley.
White background is transparent. Raster edge colours are approximated with smooth
vector contours in six tonal layers; the SVG contains no embedded bitmap.

The header uses the same contours from shared/company-logo.ts through
shared/BrandIcon.astro. Its colours derive from the current palette and theme.
The standalone SVG has original grey/green fallback colours, and CSS custom
properties for inline use (--accent, --bg, --text, --brand-secondary).
External img elements do not inherit the embedding page's CSS variables.

The SVG is also used as the favicon, with its original grey/green fallback colours.
The original PNG is retained unchanged as a source/reference.
