# Clock background assets

Original, static SVG illustrations for a future clock background picker.
No scripts, animation, embedded bitmaps, fonts, or external resources.

Open `preview.svg` to compare all twelve motifs in a self-contained contact sheet.

All assets share a `1600 × 1000` viewBox and `xMidYMid slice` scaling.
Use as CSS backgrounds with `background-size: cover` and centered positioning;
the composition also accommodates portrait cropping. Features are concentrated
toward the edges, leaving a calm central area for the clock.

Use decorative backgrounds rather than accessible inline illustrations behind
the clock. Choose a light or dark overlay for sufficient readout contrast;
the artwork alone does not guarantee legibility with every clock theme.

The clock settings offer these motifs with thumbnails and a "no background"
option. Artwork appears in normal and focus view, with a theme-aware overlay and
subtle text shadows for contrast. There is no extra readout panel around the
time and date. Selection persists only with storage consent.
Custom uploads and adjustable contrast controls are not implemented yet.
