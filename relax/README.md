# Jacktools Relax
Static Astro soundscape for https://relax.jacktools.net, based on Breathe.
Node >=24.17.0. npm ci, npm run dev, npm test, npm run build, npm run test:e2e.
Deploy the complete dist/ to the domain root on the same 1blu Ubuntu/Plesk setup.
No deployment or hosting changes are made by a build.

DE/EN/ES/FR, shared palette/style/font settings, bilingual legal documents.
Locally synthesised wind chimes, singing bowls, kalimba, handpan, bells, gong and harp.
Instrument playback can be disabled independently of the background layers.
Optional synthesised rain, gusting wind, fireplace, brook and white/pink/brown noise
with individual volume controls. Fireplace crackle density and brook flow are adjustable
live, with independent optional audio-timed ember/water animations.
Editable presets include Summer garden, Evening calm, Gentle companion, Nature only,
By the fire and Forest brook; they preserve session duration and general preferences.
The sounds approximate instruments/environmental textures; they are not field recordings.
Warm tone-specific shapes, motion-off/reduced-motion support, fullscreen and wake lock.
Timed sessions fade out; 0 minutes is unlimited. No autoplay or saved running sessions.
Background audio is opt-in per switch (enabled by default for bedtime); browser/device
restrictions still apply. Animation stops in the background. Disabling background playback
pauses and requires explicit resume. Do not rely on this tool as an alarm.
Safety introduction, always-accessible guidance and immediate end controls follow Breathe.
Preferences/safety status persist only with existing explicit storage consent.
