# Relax backgrounds

Local static SVG illustrations, 1600 × 1000, centered cover cropping.
No scripts, fonts, remote resources or added motion. General motifs are reused
from Clock; the six preset scenes were authored specifically for Relax:

- summer-garden: flowering meadow, shrubs, trees, summer sky and distant sea.
- evening-terrace: wooden terrace, potted plants and soft string lights.
- focus-room: minimal room, garden window, desk and sleeping Breathe cat.
- forest-clearing: layered woodland, open clearing and ferns.
- lakeside-camp: two tents, lake, stars and campfire.
- quiet-coast: shore, soft surf, rocks and coastal grasses (current ocean preset).

The focus cat reuses the exact geometry from Breathe's CandleBackground.astro,
with static warm colours instead of its theme CSS and breathing animation.
Preset changes select these scenes; changing a scene leaves the sound untouched.
Existing general backgrounds remain available. Persistence uses existing consent.
